# akashic-unicode-props — Unicode Text Properties

One lookup gives every Unicode property the shared text contract
([`docs/rich-terminal/APT-1-TEXT.md`](../rich-terminal/APT-1-TEXT.md))
uses, packed into one value.  The data is Unicode 15.1.0.

```forth
REQUIRE text/unicode-props.f
```

`PROVIDED akashic-unicode-props` — safe to include multiple times.

---

## Where the data comes from

`text/unicode-tables.f` is generated by
`local_testing/generate_unicode_text_tables.py` from exactly the Unicode
Character Database files the contract names.  The generator checks each
file's SHA-256 against the published Unicode 15.1.0 bytes, so a different
version cannot slip in, and `--check` proves the checked-in tables are
current.  Never edit the tables by hand.

| Table | Contents |
|-------|----------|
| `UT-VALUES` | Distinct packed property values (100 in 15.1.0). |
| `UT-RANGES` | One cell per run of equal values: value index << 32 \| first scalar. |
| `UT-MIRRORS` | Scalar << 32 \| Bidi_Mirroring_Glyph. |
| `UT-BRACKETS` | Scalar << 32 \| canonical pair << 2 \| type (1 open, 2 close). U+2329 and U+232A pair through their canonical equivalents. |
| `UT-ARABIC` | Two cells per letter: letter << 32, then its isolated, final, initial, and medial presentation forms in 16-bit fields. |

At load time the module fills a 64 KiB byte table with the value index of
every Basic Multilingual Plane scalar, walking the runs once.  After that a
BMP lookup is one byte load; a supplementary scalar, such as most emoji,
binary-searches the runs above U+FFFF.

---

## Packed properties

`UP-PROPS ( cp -- props )` returns the packed value.  A value past
U+10FFFF, or negative, reads as U+FFFD.  The field words take it apart:

| Word | Bits | Property |
|------|------|----------|
| `UP-GCB` | 0–3 | Grapheme_Cluster_Break (`UP-GCB-OTHER` … `UP-GCB-LVT`) |
| `UP-EXTPICT?` | 4 | Extended_Pictographic |
| `UP-INCB` | 5–6 | Indic_Conjunct_Break (`UP-INCB-NONE`, `-CONSONANT`, `-EXTEND`, `-LINKER`) |
| `UP-WIDTH` | 7–8 | Scalar width `w(s)`: 0, 1, or 2 |
| `UP-EMOJI?` | 9 | Emoji |
| `UP-EMOJI-MODIFIER?` | 10 | Emoji_Modifier |
| `UP-IGNORABLE?` | 11 | Default_Ignorable_Code_Point |
| `UP-INVALID?` | 12 | General_Category `Cc`, `Zl`, or `Zp` |
| `UP-BIDI` | 13–17 | Bidi_Class (`UP-BC-L` … `UP-BC-PDI`), with the UCD's defaults for unassigned scalars |
| `UP-JOINING` | 18–20 | Joining_Type (`UP-JT-U`, `-D`, `-R`, `-L`, `-C`, `-T`) |
| `UP-MIRRORED?` | 21 | Has a Bidi_Mirroring_Glyph |
| `UP-BRACKET?` | 22 | Is a paired bracket |
| `UP-ARABIC-FORMS?` | 23 | Has an Arabic presentation form |

## Other lookups

| Word | Stack | Result |
|------|-------|--------|
| `UP-MIRROR` | `( cp -- cp' )` | The mirroring glyph, or `cp` itself |
| `UP-BRACKET` | `( cp -- pair type )` | Paired bracket and type 1 open or 2 close; `0 0` if none |
| `UP-ARABIC-FORM` | `( cp form -- cp' \| 0 )` | Presentation form for `UP-FORM-ISOLATED`, `-FINAL`, `-INITIAL`, or `-MEDIAL`; 0 if none |

## Concurrency

The tables never change after load and every word keeps its state on the
data stack, so all of them are reentrant without a guard.

## Tests

`local_testing/test_unicode_text.py` checks the Forth lookup at the first,
middle, and last scalar of every run, every mirror, bracket, and Arabic
form, and that the checked-in tables match the data.
