# akashic-fp32 — IEEE 754 Binary32 for KDOS / Megapad-64

Single-precision (FP32) scalar arithmetic on MegaPad's scalar FP32
instructions (the `F32` BIOS words). Used for final-stage statistics,
audio setup, and LIRAQ expression values.

```forth
REQUIRE fp32.f
```

`PROVIDED akashic-fp32` — safe to include multiple times.

---

## Design

| Principle | Detail |
|---|---|
| **Correctly rounded** | Every result is the IEEE 754 result rounded in the rounding mode in `FPCSR`: round to nearest even unless a caller changes it. `FP32-FMA` rounds once. |
| **IEEE special values** | ±0, subnormals, ±∞, and NaN behave as IEEE 754 specifies. Every NaN result is the canonical quiet NaN, `FP32-NAN`. |
| **Raw bit patterns** | A value is a 32-bit pattern in the low half of a 64-bit cell. Inputs ignore the high half, and results clear it. |
| **No state** | The words keep no module state, so any task or core may use them. |

## Constants

| Word | 32-bit hex | Value |
|---|---|---|
| `FP32-ZERO` | `0x00000000` | +0.0 |
| `FP32-ONE` | `0x3F800000` | 1.0 |
| `FP32-HALF` | `0x3F000000` | 0.5 |
| `FP32-TWO` | `0x40000000` | 2.0 |
| `FP32-PI` | `0x40490FDB` | π |
| `FP32-E` | `0x402DF854` | e |
| `FP32-INF` | `0x7F800000` | +∞ |
| `FP32-NAN` | `0x7FC00000` | canonical quiet NaN |

## Arithmetic

| Word | Stack | Result |
|---|---|---|
| `FP32-ADD` | `( a b -- a+b )` | Sum |
| `FP32-SUB` | `( a b -- a-b )` | Difference |
| `FP32-MUL` | `( a b -- a*b )` | Product |
| `FP32-DIV` | `( a b -- a/b )` | Quotient; ±∞ for a nonzero value over ±0 |
| `FP32-FMA` | `( a b c -- a*b+c )` | Fused multiply-add, one rounding |
| `FP32-SQRT` | `( a -- √a )` | Square root; NaN for a negative value |
| `FP32-RECIP` | `( a -- 1/a )` | Reciprocal, correctly rounded |
| `FP32-NEGATE` | `( a -- -a )` | Flips the sign bit |
| `FP32-ABS` | `( a -- \|a\| )` | Clears the sign bit |

```forth
FP32-ONE FP32-TWO FP32-ADD .   \ → 1077936128 (0x40400000 = 3.0)
```

## Comparison

Comparisons return a Forth flag (0 false, −1 true). They are false
whenever either value is NaN, and −0 equals +0.

| Word | Stack | Result |
|---|---|---|
| `FP32<` | `( a b -- flag )` | a < b |
| `FP32>` | `( a b -- flag )` | a > b |
| `FP32=` | `( a b -- flag )` | a = b |
| `FP32<=` | `( a b -- flag )` | a ≤ b |
| `FP32>=` | `( a b -- flag )` | a ≥ b |
| `FP32-0=` | `( a -- flag )` | a is −0 or +0 |
| `FP32-MIN` | `( a b -- min )` | Minimum; NaN if either is NaN; −0 below +0 |
| `FP32-MAX` | `( a b -- max )` | Maximum; NaN if either is NaN; −0 below +0 |

## Conversions

A fixed-point value (`fixed.f`) is a signed cell whose low 16 bits are the
fraction. Conversions to an integer or to fixed point truncate toward zero,
give 0 for NaN, and saturate at the cell's range.

| Word | Stack | Result |
|---|---|---|
| `FP16>FP32` | `( fp16 -- fp32 )` | Exact, subnormals included |
| `FP32>FP16` | `( fp32 -- fp16 )` | Rounded, with FP16 subnormals and overflow to ±∞ |
| `INT>FP32` | `( n -- fp32 )` | Rounded |
| `FP32>INT` | `( fp32 -- n )` | Toward zero |
| `FX>FP32` | `( fx -- fp32 )` | Rounded |
| `FP32>FX` | `( fp32 -- fx )` | Toward zero |
| `ACC>FP32` | `( -- fp32 )` | Low 32 bits of the tile accumulator (ACC@, CSR 0x19): the binary32 result of an FP16 or BF16 reduction |

```forth
0x3C00 FP16>FP32 .   \ FP16 1.0 → 1065353216 (FP32 1.0)
0x3FC00000 FP32>FX . \ 1.5 → 98304
```
